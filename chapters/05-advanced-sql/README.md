# 📖 Chapter 5: Advanced SQL

> **Textbook:** *Database System Concepts (7th Edition)*  
> **Status:** ⏳ Upcoming

## 🎯 Key Topics in this Chapter
- [ ] **Accessing SQL from Programming Languages**: Dynamic vs. Embedded SQL, JDBC, and ODBC.
- [ ] **Functions and Procedures**: Stored procedures, PL/SQL / PL/pgSQL routines.
- [ ] **Triggers**: Event-driven execution (`BEFORE/AFTER INSERT/UPDATE/DELETE`).
- [ ] **Recursive Queries**: Transitive closure using recursive CTEs (`WITH RECURSIVE`).
- [ ] **Advanced Aggregation & OLAP**: Ranking functions (`RANK()`, `DENSE_RANK()`), Windowing functions (`OVER (PARTITION BY ...)`), and Rollup/Cube operations.
